# RigolPlot

Датологгер для осциллографа **Rigol DHO900** (DHO914S/DHO924S и аналоги) через SCPI по TCP/VXI-11. Один файл исходника, Windows, WinForms, .NET Framework 4.x.

![Язык](https://img.shields.io/badge/язык-C%23-blue)
![.NET](https://img.shields.io/badge/.NET-Framework%204.x-512BD4)

## Возможности

- Опрос измерений (VRMS, VAVG) по выбранным каналам CH1–CH4 по расписанию, без накопления ошибки времени;
- Интервал записи от 10 мс (по умолчанию 100 мс);
- Запись в CSV рядом с exe (`rigol_ch1_vavg_<дата>.csv`);
- Живой график: зум прямоугольником по осям, автомасштаб (F), полный вид (R / правая кнопка), курсор;
- Единицы каналов (В/А/Вт/ед.) читаются из прибора (`:CHAN<n>:UNIT?`) и обновляются каждые 5 с;
- Предупреждение, если временная развёртка прибора больше 10 мс (`:TIMebase:SCAL?`);
- Пороги с тревогой и звуком;
- Экспорт графика в JPG;
- Тёмная/светлая темы (палитра каналов как у DHO900);
- Автопереподключение при потере связи (до 10 попыток, строки NaN);
- Запоминание последнего IP прибора в `RigolPlot.ini` рядом с exe.

## Сборка

Компилятор C# из .NET Framework SDK (csc.exe):

```powershell
& "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe" `
  /nologo /target:winexe /optimize+ `
  /out:"RigolPlot.exe" `
  /win32manifest:"RigolPlot.manifest" `
  "RigolPlot.cs"
```

Приложение рассчитано на запуск под Windows, один exe без зависимостей.

## Использование

1. Укажите IP осциллографа (порт 5555), выберите интервал, каналы и величину;
2. «Пуск» — начнётся запись и отрисовка графика;
3. «Стоп» — остановка; CSV остаётся рядом с exe;
4. «Открыть CSV…» — просмотр записанного файла; «Экспорт JPG» — сохранение графика в картинку;
5. Изменения масштаба прибора (развёртка, единицы) подхватываются автоматически.

Формат CSV: заголовок `time_s;voltage_<param>_chN;...`, значения через `;`, время в секундах от начала записи.

## SCPI-команды

| Назначение | Команда |
|---|---|
| Измерение | `:MEAS:ITEM? VRMS,CHAN1` |
| Единица канала | `:CHAN1:UNIT?` (`VOLT`/`AMP`/`WATT`/`UNKN`) |
| Развёртка | `:TIMebase:SCAL?` (с/дел) |

## Структура

- `RigolPlot.cs` — весь исходник (WinForms, графика, SCPI);
- `RigolPlot.manifest` — манифест DPI-awareness;
- `RigolPlot.exe` — собранное приложение;
- `RigolPlot.ini` — настройки (IP), создаётся при работе, в репозиторий не включается;
- `*.csv` — лог-файлы, в репозиторий не включаются.
